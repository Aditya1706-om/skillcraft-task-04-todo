# skillcraft-task-04-todo
Responsive To-Do Web Application developed for SkillCraft Technology Web Development Internship - Task 04.
📝 To-Do Web Application

A responsive and interactive **To-Do Web Application** developed as part of my **Web Development Internship at SkillCraft Technology — Task 04**.

The application allows users to add, organize, edit, complete, and delete tasks while also setting a date and time for each task.

---

 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🔄 Mark completed tasks as pending
- 📅 Set task date
- ⏰ Set task time
- 📋 View all tasks
- 🔵 View pending tasks
- 🟢 View completed tasks
- 📊 Task statistics
- 💾 Local Storage support
- 📱 Responsive design
- 🎨 Modern user interface

---

 🛠️ Technologies Used

- **HTML5** — Application structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Task management and DOM manipulation
- **LocalStorage** — Persistent task data
